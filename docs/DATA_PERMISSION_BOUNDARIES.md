# 数据权限边界清单

## 当前规则

- 普通租户用户只能访问自己 `tenant_id` 下的数据。
- 普通租户用户传入 `tenant_id` 查询参数时，后端忽略该参数，仍使用登录用户所属租户。
- 平台管理员可以通过 `tenant_id` 查询参数切换目标租户；未传时默认使用租户 `1`，保持现有开发数据兼容。
- 无登录上下文的兼容路径仍按原有逻辑读取 `tenant_id` 查询参数，未传时默认为 `1`。

## 已收口接口

- 用户：列表、创建、更新、重置密码、删除。
- 角色：可分配角色、列表、详情、创建、更新、删除。
- 组织：组织树、组织详情、创建、更新、删除。
- 业务单元：列表、树、创建、更新、删除、组织映射列表、组织映射创建、组织映射删除。

## 测试覆盖

- `effectiveTenantID` 已覆盖平台管理员可切换租户、普通租户用户不可通过查询参数越权、无登录上下文保留兼容回退。

## 后续扩展

- 字典、系统参数、岗位等租户字段已存在但仍有兼容路径，后续按相同规则继续收口。
- 后续业务级 E2E 需要增加跨租户数据准备，并验证普通用户看不到其他租户的数据。
