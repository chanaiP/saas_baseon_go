# 通用 GEO 母稿生成 Skill

```yaml
skill_code: universal_geo_master_draft_generator
skill_name: 通用 GEO 母稿生成 Skill
skill_type: master_draft_generation
version: v2.0
```

## 1. Skill 定位

`通用 GEO 母稿生成 Skill` 是 AI GEO 工作台统一使用的正式写稿能力。

它不再按多个独立 Skill 分流，而是使用同一个内部生成能力，根据前端传入的「内容类型」决定文章写法。

它只负责正式写稿，不负责聊天、追问、推荐方向或解释原因。

目标是根据 AI 工作台调度层收敛出的 `draft_brief`，结合品牌资料、商品资料、内容类型、关键词和用户上下文，生成一份可进入右侧母稿编辑器、可继续审核、可继续改写为多渠道内容的 GEO 内容母版。

母稿不是普通文章，而是后续小红书、知乎、公众号、抖音、视频脚本和问答内容共同复用的内容源文件。

## 2. 核心目标

生成的母稿必须满足：

1. 回答一个真实搜索问题或 AI 问答问题。
2. 解释品牌实体、商品价值和适用场景。
3. 覆盖人群词、场景词、问题词和品牌关键词。
4. 保持事实可信，不虚构资料库外事实。
5. 降低硬广感，避免关键词堆砌。
6. 可作为小红书、知乎、公众号、抖音、微博、百家号、独立站等渠道内容的源稿。

## 2.1 内容母版结构

生成结果正文必须优先包含以下模块：

1. 主题定位：核心问题、目标用户、用户为什么会搜索或提问。
2. 核心答案：用 3-5 句话直接回答主题，适合被 AI 摘要、引用、转述。
3. 品牌/产品定义：品牌是什么、解决什么问题、适合谁、不适合谁。
4. 用户决策逻辑：为什么需要它、和替代方案相比有什么区别、选择标准是什么。
5. 证据与论点：事实依据、场景依据、用户痛点、品牌优势、可验证信息。
6. FAQ：覆盖用户最可能问的问题，每个问题给短答案。
7. GEO 优化结构：实体词、问题词、对比词、场景词、长尾搜索表达。
8. 渠道改写素材：小红书角度、知乎角度、抖音角度、公众号角度。

## 3. 输入参数

生成母稿时，系统会向 AI 提供以下输入：

```json
{

    "geo_goal": ["GEO目标"],
    "risk_flags": ["风险点"]
  },
  "brand_id": "品牌 ID，可为空",
  "product_id": "商品 ID，可为空",
  "skill": "通用母稿生成 Skill",
  "content_type": "内容类型",
  "hotspot_id": "热点 ID，可为空",
  "conversation": "工作台对话上下文",
  "source_snapshot": "品牌、商品、关键词、内容类型、brief 等生成依据",
  "prompt": "用户原始想法或收敛后的生成 brief"
}
```

## 4. 内容类型

内容类型由数据字典维护，默认值为 `通用母稿`。

当前默认类型：

1. 通用母稿
2. 商品种草文
3. 商品测评文
4. 商品对比文
5. 场景解决方案
6. 品牌介绍文
7. FAQ 问答文
8. 榜单推荐文
9. 热点借势文
10. 活动营销文

## 5. 内容类型写作策略

### 通用母稿

适合未明确内容方向时使用。

写法：

1. 先回答用户问题。
2. 再解释品牌或商品是什么。
3. 补充适合人群、适合场景和选择理由。
4. 最后给出结论和注意事项。

### 商品种草文

强调商品卖点、适用人群和购买理由。

写法：

1. 先说明这件商品解决什么问题。
2. 再解释卖点与场景。
3. 补充适合谁、不适合谁。
4. 最后给出自然的选择建议。

### 商品测评文

强调体验、优缺点、适用边界和真实感。

写法：

1. 先给结论。
2. 再分维度测评体验。
3. 说明优点、限制和适合人群。
4. 避免夸大功效和虚构真实体验。

### 商品对比文

强调差异、选择标准和适用边界。

写法：

1. 先说明对比问题。
2. 再从风格、价格、场景、卖点等维度比较。
3. 给出不同需求下的选择建议。
4. 不虚构竞品事实。

### 场景解决方案

围绕通勤、约会、旅行、办公等具体场景给出解决方案。

写法：

1. 先描述场景痛点。
2. 再给解决思路。
3. 引出品牌或商品如何承接。
4. 最后给可执行的搭配、选择或使用建议。

### 品牌介绍文

解释品牌定位、适合人群和品牌价值。

写法：

1. 先回答“这是什么品牌”。
2. 再说明品牌风格、目标人群、核心识别点。
3. 补充适合哪些场景和用户。
4. 避免写成品牌宣传稿。

### FAQ 问答文

适合搜索问答和 AI 问答引用。

写法：

1. 使用真实问题作为入口。
2. 每个回答先给结论，再解释理由。
3. 覆盖品牌、人群、场景、商品和注意事项。
4. 保持短句和清晰结构。

### 榜单推荐文

适合推荐清单、排行榜、选购合集。

写法：

1. 先说明榜单标准。
2. 再给推荐理由。
3. 每个推荐项说明适合谁。
4. 不虚构排名、销量或奖项。

### 热点借势文

结合热点做轻引用，不强行蹭热点。

写法：

1. 先说明热点与用户问题的关系。
2. 再自然过渡到品牌或商品。
3. 只做观点承接，不夸大热点关联。
4. 避免编造时效信息。

### 活动营销文

围绕活动、上新、促销、节日节点生成内容。

写法：

1. 先说明活动核心信息。
2. 再解释适合谁关注。
3. 给出行动建议和注意事项。
4. 不承诺未确认的价格、库存、权益。

## 6. 生成决策规则

### AI 可以直接判断

1. 母稿标题方向。
2. 文章结构。
3. 内容长度。
4. 表达语气。
5. GEO 关键词覆盖。
6. 是否增加 FAQ。
7. 是否强化人群、场景或选择理由。

### 必须谨慎处理

以下内容只有资料明确时才能写：

1. 真实用户案例。
2. 竞品品牌名称和对比结论。
3. 价格承诺。
4. 功效、产地、销量、认证。
5. 官方背书、行业第一、唯一等绝对化表述。
6. 资料库外的素材和事实。

## 7. 母稿结构建议

推荐结构：

1. 直接回答问题。
2. 品牌或商品是什么。
3. 适合哪些人。
4. 适合哪些场景。
5. 为什么适合。
6. 不适合哪些情况或注意事项。
7. FAQ。
8. AI 可引用总结句。

不是每篇都必须机械包含所有模块，但必须优先保证“问题回答 + 品牌实体 + 场景解释 + 可信依据”。

## 8. 生成提示词

前端生成母稿时，会拼接以下核心提示词：

```text
你是 AI GEO 母稿协作编辑。请根据用户选择的资料、内容类型和聊天中收敛出的 brief 生成一篇可作为多渠道源稿的 GEO 母稿。

当前触发方式：用户已经点击“生成母稿”，这代表用户选择 AI 共创/委托生成。你必须直接写完整母稿，禁止继续追问、要求确认或让用户选择篇幅。

如果缺少目标人群、场景、篇幅、口吻、商品或热点，请基于品牌资料、商品资料、内容类型、关键词和对话自行合理推断并补齐，不得阻塞生成。

生成目标：先回答用户真实搜索/AI 问答问题，再自然带出品牌与商品资料；避免空泛品牌介绍和硬广。

重要边界：这是写入右侧母稿编辑器的文章资产，不是聊天回复。禁止出现“好的、明白、我建议、请确认、现在可以生成、母稿使用说明、替换占位符、请补充、你希望、是否可以、还差一个点”等沟通过程或操作说明。

正文必须是一篇完整文章：标题、摘要、正文分别返回；正文只写可发布内容，不要写创作过程。

输出要求：标题明确、摘要可发布、正文有问题拆解/选择理由/场景建议/结论，关键词可供渠道改写复用。只输出文章本身。
```

后端 AI Gateway 会追加系统级约束：

```text
你是一个熟悉 GEO 内容增长、品牌种草和渠道改写的内容策略专家。

你必须基于输入的品牌、商品、技能、用户提示和对话收敛结果，生成可审核的中文母稿。

母稿是可发布正文资产，不是聊天回复；严禁输出“好的、明白、我建议、请确认、现在可以生成、母稿使用说明”等沟通过程话术。

如果 recent_titles 非空，title 必须避开这些历史标题，换一个具体内容角度，不得复用同一句标题或只做标点改写。

body 只能包含文章正文：开头、观点/方案、场景建议、选择理由、结论；不要包含生成说明、替换占位符、导师分析或确认问题。

只返回合法 JSON，不要 Markdown，不要解释性前后缀。
```

AI 必须返回合法 JSON：

```json

  "body": "完整可发布文章正文，只写文章内容，不写聊天确认、不写创作说明、不写使用说明",
```

## 10. 标题规则

标题必须：

1. 明确对应一个真实问题或内容入口。
2. 不超过 42 个中文字符。
3. 同品牌、同内部生成能力下避免重复历史标题。
4. 不用空泛模板，例如“某品牌适合哪些人？一篇看懂选择思路”反复出现。
5. 不使用夸大承诺、绝对化表述。

## 11. 正文禁止项

正文中禁止出现：

1. 好的、明白、收到。
2. 我建议、我会、我可以。
3. 请确认、请补充、你希望。
4. 现在可以生成、点击生成母稿。
5. 母稿使用说明。
6. 替换占位符。
7. 生成方向、输出要求、输入上下文。
8. 未确认的品牌历史、销量、认证、产地、功效、价格承诺。

## 12. 质量验收标准

合格母稿应满足：

1. 标题、摘要、正文一致。
2. 开头直接回答问题。
3. 正文能解释品牌或商品为什么适合目标人群。
4. 有具体场景，不只是泛泛介绍。
5. 有选择理由和适用边界。
6. 语言自然，不硬广。
7. 没有聊天话术和创作说明。
8. 可继续生成渠道内容。
