# 删除/归档引用约束

## 当前规则

- 基础资料被其他业务数据引用时，不允许直接删除。
- 删除前由后端做引用计数校验，命中引用时返回明确业务错误。
- 已有软删除字段的模型仍保留软删除能力，但软删除前同样执行引用保护。

## 已覆盖约束

| 删除对象 | 阻断引用 |
| --- | --- |
| 权限 | 子权限、角色权限、租户菜单覆盖 |
| 主体 | 用户、组织、业务单元、套餐订阅 |
| 套餐 | 主体套餐订阅 |
| 组织 | 下级组织、用户主组织、用户兼任部门、业务单元组织映射 |
| 岗位类型 | 岗位 |
| 岗位 | 用户岗位 |
| 业务单元 | 组织映射、数据权限范围 |
| 字典类型 | 字典项 |
| 字典项 | 租户字典覆盖 |
| 系统参数 | 租户参数值 |

## 后续扩展

- 对“停用/归档后可删除”的产品规则做更细粒度状态机。
- 对套餐功能、套餐配额等配置型关联根据产品规则区分“可级联清理”和“禁止删除”。
