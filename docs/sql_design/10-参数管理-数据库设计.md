# 10-参数管理-数据库设计

## 1. 模块范围

参数管理采用默认定义加租户覆盖模式。平台维护 `sys_param` 默认定义，租户通过 `tenant_param_value` 保存当前主体覆盖值。

## 2. 关联表清单

| 表名 | 说明 |
|---|---|
| `sys_param` | 系统参数默认定义 |
| `tenant_param_value` | 租户参数覆盖值 |

## 3. 表结构

### 3.1 `sys_param`

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | Integer | PK, index | 参数 ID |
| `tenant_id` | Integer | FK tenant.id, not null, index | 主体 ID |
| `param_key` | String(128) | not null | 参数键 |
| `param_value` | Text | nullable | 默认值 |
| `remark` | String(500) | nullable | 备注 |
| `value_type` | String(32) | default STRING | STRING/NUMBER/BOOLEAN/JSON |
| `tenant_editable` | Boolean | default true | 租户可编辑 |
| `is_platform_only` | Boolean | default false | 平台专属 |
| `deleted_at` | DateTime | nullable | 逻辑删除 |

唯一约束：`(tenant_id, param_key)`。

### 3.2 `tenant_param_value`

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | Integer | PK, index | 主键 |
| `tenant_id` | Integer | FK tenant.id, not null, index | 主体 ID |
| `param_id` | Integer | FK sys_param.id, not null, index | 参数 ID |
| `param_value` | Text | nullable | 覆盖值 |
| `created_at` | DateTime | default now | 创建时间 |
| `updated_at` | DateTime | default now | 更新时间 |

唯一约束：`(tenant_id, param_id)`。

## 4. 覆盖读取规则

```text
当前参数值 = tenant_param_value.param_value ?? sys_param.param_value
```

租户恢复默认时删除 `tenant_param_value` 行。

## 5. 参数类型

| `value_type` | 说明 |
|---|---|
| `STRING` | 字符串 |
| `NUMBER` | 数字 |
| `BOOLEAN` | 布尔 |
| `JSON` | JSON 文本 |

类型值校验强度需结合 service 实现确认【待确认】。

## 6. 逻辑删除

`sys_param.deleted_at` 表示参数归档。覆盖值删除是恢复默认，不属于业务主数据删除。

## 7. 风险与待确认

| 类型 | 内容 |
|---|---|
| 类型校验 | JSON/NUMBER/BOOLEAN 的严格校验规则需确认 |
| 引用检查 | 已被业务功能引用的参数是否允许归档需确认 |
| 安全参数 | 敏感参数是否需要加密或脱敏展示需确认 |
