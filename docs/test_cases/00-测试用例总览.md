# 测试用例总览

## 1. 文档说明

本文档用于统一系统管理模块测试用例入口，支撑产品验收、开发自测、测试执行和 AI 编程助手回归检查。测试范围来自当前 `docs/req_design`、`docs/tech_design`、`docs/sql_design` 与实际前后端代码；当文档与代码不一致时，以当前代码为准，并在用例备注或待确认事项中标记【文档与实现不一致】或【待确认】。

适用对象包括产品、研发、测试、实施和后续 AI coding agent。本文档不包含自动化测试代码，也不代表已经执行测试。

## 3. 测试类型

| 测试类型 | 说明 |
|---|---|
| 功能测试 | 验证新增、编辑、删除、查询、详情、状态变更等功能 |
| 权限测试 | 验证菜单权限、按钮权限、接口权限 |
| 数据权限测试 | 验证主体、组织、业务单元、本人数据等范围控制 |
| 接口测试 | 验证接口入参、出参、异常响应和统一响应结构 |
| 数据库约束测试 | 验证唯一约束、关联约束、逻辑删除、状态字段和审计字段 |
| 异常测试 | 验证必填、重复、数据不存在、权限不足、配额不足等异常 |
| 日志测试 | 验证关键操作是否记录操作日志或登录日志 |
| 回归测试 | 验证核心链路在修改后不被破坏 |

## 4. 测试优先级定义

| 优先级 | 含义 | 示例 |
|---|---|---|
| P0 | 核心主流程，必须通过 | 登录、用户授权、角色菜单权限、tenant 隔离、套餐配额拦截 |
| P1 | 重要业务流程，建议每次回归 | 新增、编辑、逻辑删除、启用禁用、角色授权 |
| P2 | 一般场景 | 查询筛选、列表展示、备注字段、空状态 |
| P3 | 低频或增强场景 | 导入导出、批量操作、扩展能力 |

## 5. 通用测试检查清单

- 菜单是否可见，直接访问路由是否被拦截。
- 查询、筛选、重置、分页和空状态是否正常。
- 新增、编辑、逻辑删除、状态变更是否符合权限和租户范围。
- 必填、重复、长度、格式、非法状态等校验是否生效。
- 按钮权限和接口权限是否同时生效。
- 主体隔离、组织数据权限、业务单元数据权限是否生效。
- 套餐功能矩阵和配额限制是否在前端体验与后端校验中同时生效。
- 业务数据删除是否为逻辑删除，历史和审计是否可追溯。
- 操作日志、登录日志是否准确记录并按主体隔离。
- 字典翻译和参数读取是否使用当前租户有效值。
- 异常提示是否清晰，不泄露 SQL、堆栈、token 或内部实现。

## 6. 测试数据准备建议

| 数据 | 建议 |
|---|---|
| 平台管理员 | 具备系统管理全量权限，用于验证平台专属菜单和跨主体筛选 |
| 租户管理员 | 具备本主体系统管理权限，用于验证 tenant 隔离和租户内操作 |
| 普通用户 | 仅具备少量菜单或无按钮权限，用于验证权限拒绝 |
| 主体数据 | 至少两个普通主体，一个平台主体，一个停用主体，一个归档主体 |
| 组织数据 | 公司、部门、门店多层级，并准备跨主体组织 |
| 业务单元 | 启用、禁用、已引用、已归档数据各一组 |
| 角色权限 | 全权限角色、只读角色、无权限角色、数据权限不同范围角色 |
| 套餐配额 | TRIAL/BASIC/PRO/ENTERPRISE，以及自定义覆盖配额 |
| 日志数据 | 登录成功、登录失败、关键操作成功和失败记录 |

## 7. 回归测试建议

每次系统管理、权限、套餐、tenant、字典参数、日志或基础资料改动后，至少回归：登录、菜单加载、角色授权、用户授权、数据权限、主体隔离、套餐功能拦截、配额拦截、逻辑删除、操作日志和登录日志。

## 8. 文档与实现不一致汇总

| 类型 | 内容 | 影响 | 建议 |
|---|---|---|---|
| 实现差异 | 主体创建当前存在 `/api/tenants` 单独创建和 `/api/tenants/with-package` 合并创建；业务规则要求主体和套餐配置分两步保存 | 测试时需覆盖两个入口，并确认最终产品口径 | 若确定分步为唯一口径，后续应收敛接口和页面入口 |
| 实现差异 | 角色权限文档中有启停描述，但当前技术文档指出 `role` 未发现状态字段 | 角色启停用例只能标记【待确认】 | 如需要角色停用，补字段和接口；否则文档改为不支持 |
| 实现差异 | 岗位状态能力不明确，数据库文档提示岗位表未发现 `status` 字段 | 岗位启停测试不可作为强验收项 | 明确是否需要岗位启停 |
| 待确认 | 部分读取型接口如字典/参数批量读取、日志查询的权限范围需按当前代码确认 | 影响接口安全测试边界 | 对读取接口建立权限清单 |
| 待确认 | 日志必记操作清单、保留周期、归档策略未完全确定 | 影响审计验收 | 建立审计事件清单和日志保留策略 |

## 9. 待确认事项汇总

| 类型 | 内容 | 影响 |
|---|---|---|
| 需求待确认 | 已被业务引用的数据是否允许归档、归档后历史展示口径 | 影响基础资料删除测试 |
| 权限待确认 | 租户管理员是否允许查看部分平台默认配置的只读信息 | 影响菜单和接口权限测试 |
| 数据权限待确认 | 组织和业务单元范围是否覆盖所有系统管理查询 | 影响越权风险验证 |
| 套餐待确认 | 套餐降级后已超额资源是否只禁止新增还是要求整改 | 影响配额边界测试 |
| 日志待确认 | 权限拒绝、套餐拒绝、配额拒绝是否都记录失败审计 | 影响安全审计完整性 |
