# 企业级 SaaS 底座优化 TODO

> 目标：在不扩展业务需求、不新增产品功能、不改变既有菜单与交互语义的前提下，把当前 SaaS 底座优化到企业级可维护、安全、稳定、高性能的工程标准。

## 执行原则

- 只优化现有问题，不额外扩展需求和功能。
- 每完成一项必须打勾，并保留对应验证方式。
- 涉及租户、权限、套餐、配额、菜单、角色的数据链路，必须同时检查前后端、初始化数据和测试。
- 生产安全、租户隔离、迁移治理、逻辑删除和审计优先于界面细节。
- 老项目代码和 SQL 只允许查看对照，不允许修改。
- 不把可选技术路线写成必做项；只有直接修复当前底座风险、降低维护成本或形成安全基线的事项才进入 TODO。
